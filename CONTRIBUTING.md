# Contributing to PlayCast

Use Node.js 22 or newer and Windows x64 for Electron and installer verification. Run `npm ci`, then `npm run dev`. On PowerShell, use `npm.cmd` if local script policy blocks `npm`.

Keep changes focused and use concise imperative commit subjects. Before submitting a pull request, run `npm run typecheck`, `npm test`, `npm run build`, and relevant Electron smoke scenarios. Describe behavior changes and link the issue; add screenshots for UI changes. Report real-account/live-game checks separately from synthetic fixtures.

Write Electron source in `.cts` and renderer source in `.ts`/`.tsx`. CommonJS `.cjs` files in `electron/` and `public/main-appearance.js` are regenerated by the build; edit their TypeScript sources. Keep IPC/data contracts typed, preserve runtime validation, and do not bypass checking with `any` or `@ts-nocheck`.

Never commit user profiles, cookies, credentials, generated installers, caches, or test captures. Keep changes to persistence backward compatible and test recovery/error paths. Review [development](docs/development.md), [architecture](docs/architecture.md), and [third-party notices](THIRD_PARTY_NOTICES.md) before changing the associated boundaries.
